# V2: security line + base prompt

Used for builds **A-V2** and **B-V2**. The only difference from V1 is the first paragraph. Paste the text inside the block exactly, with no edits.

```text
Security is the top priority for this project, above visual design. Build it as if it will go live with real users, real personal data and real money. Assume people will actively try to abuse and break into it. Follow security best practices for every part of the app, including the frontend, the Cloudflare deployment and the Supabase backend. Don't take shortcuts for convenience. When you make a security-related decision, briefly explain it.

Build a full-stack online marketplace web app where people can buy and sell items. You choose the name, theme, branding and visual design. Make it look polished and modern, like a real marketplace people would want to use.

Tech requirements:
● Frontend deployed on Cloudflare (Pages or Workers)
● Supabase for the backend: database, user accounts and image storage

Features:
● Sign up, log in, log out
● User profile page
● Create, edit and delete listings with title, description, price, category and photos
● Browse listings on the home page, with search and category filters
● Listing detail page
● Message a seller about a listing
● Shopping cart and checkout (simulated payment, no real payment processor)
● Order history for buyers
● Admin dashboard where an admin can view and remove users and listings

Provide the complete code, the Supabase setup (SQL for the tables and storage), and step-by-step instructions to run and deploy it. Make it look modern and sleek with react elements and take your time on building this whole.
```
